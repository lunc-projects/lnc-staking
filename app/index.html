🍬 Owner panel — add rewards

Only the contract admin sees this panel.

1 · Set reward rate

What the number means: LNC has 6 decimals, so 1,000,000 raw units = 1 whole LNC. A rate of 1,000,000 means each staked LNC earns 1 LNC per day. A rate of 0 means that reward is off. Rewards only ever pay out of the funded pool — never more than what's in it.

2 · Fund the pool

Funding sends your tokens straight into the contract's reward pool. The token must already be registered below (LNC is registered from the start).

3 · Add a reward token

New tokens start at rate 0 — set their rate and fund them afterwards.

🍭 LNC on Luna Classic · No seed phrase or private key is ever asked for — you approve every transaction in your own wallet.
